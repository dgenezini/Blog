    History expansion

    SyntaxEffect
    !!Repeat last command
    !prefixRun last command starting with prefix
    !$Last argument of previous command
    !#:1First argument of current command line
    !:1First argument of previous command
    ^old^newFind and replace in previous command
    • !CD runs the last command that started with CD.
    • !$ reruns the previous command’s argument — reuse the path from an ls in another command: envm !$.
    • !#:1 references the first argument on the current line; !:1 the first argument of the previous command.
    • ^fuzzy^fzf corrects a typo or command name in the previous command in place.

    Special parameters

    • $$ — PID of the current shell. echo $$.
    • $_ — last argument of the previous command. ls -la mydir, then echo $_ prints mydir.

    Randomness

    $RANDOM prints a pseudo-random integer from 0 to 32767 (a 16-bit maximum). Arithmetic limits the range: echo $((RANDOM % 10 + 1)) gives 1–10. It is not truly random and the modulo operator introduces bias.

    shuf (GNU coreutils) is the unbiased tool:

    1
2
3
4

    shuf my_file              # randomize lines
shuf -n 1 my_file         # one random line
shuf -i 1-1000 -n 1       # random number in range
shuf -i 1-1000            # random permutation of 1..1000

    yes repeatedly prints a string (default y) until killed — yes | sudo apt-get install -y zip automates confirmations, though it is rarely a good idea.

    Prompts and animations

    Prompt (PS1) can embed commands: branch the arrow colour on the previous exit status ($?, tested with test), or show git branch. Keep PS1 commands lightweight — they run every time the prompt is drawn.

    A spinner proves a long-running script has not hung: a while true loop printing characters with echo -n, \r to return the cursor, and sleep for pacing. A one-line clock is the same shape:

    1

    while true; do clear; date +%T; sleep 1; done

    trim_string() {
    : "${1#"${1%%[![:space:]]*}"}"
    : "${_%"${_##*[![:space:]]}"}"
    printf '%s\n' "$_"
}

trim_all() {
    set -f
    set -- $*
    printf '%s\n' "$*"
    set +f
}

regex() {
    [[ $1 =~ $2 ]] && printf '%s\n' "${BASH_REMATCH[1]}"
}

split() {   # bash 4+
    IFS=$'\n' read -d "" -ra arr <<< "${1//$2/$'\n'}"
    printf '%s\n' "${arr[@]}"
}

lower() { printf '%s\n' "${1,,}"; }        # bash 4+
upper() { printf '%s\n' "${1^^}"; }
reverse_case() { printf '%s\n' "${1~~}"; }

    urlencode() {
    local LC_ALL=C
    for (( i = 0; i < ${#1}; i++ )); do
        : "${1:i:1}"
        case "$_" in
            [a-zA-Z0-9.~_-]) printf '%s' "$_" ;;
            *) printf '%%%02X' "'$_" ;;
        esac
    done
    printf '\n'
}

urldecode() {
    : "${1//+/ }"
    printf '%b\n' "${_//%/\\x}"
}

remove_array_dups() {   # bash 4+
    declare -A tmp_array
    for i in "$@"; do
        [[ $i ]] && IFS=" " tmp_array["${i:- }"]=1
    done
    printf '%s\n' "${!tmp_array[@]}"
}

random_array_element() {
    local arr=("$@")
    printf '%s\n' "${arr[RANDOM % $#]}"
}

extract() {
    while IFS=$'\n' read -r line; do
        [[ $extract && $line != "$3" ]] && printf '%s\n' "$line"
        [[ $line == "$2" ]] && extract=1
        [[ $line == "$3" ]] && extract=
    done < "$1"
}

    dirname() {
    local tmp=${1:-.}
    [[ $tmp != *[!/]* ]] && { printf '/\n'; return; }
    tmp=${tmp%%"${tmp##*[!/]}"}
    [[ $tmp != */* ]] && { printf '.\n'; return; }
    tmp=${tmp%/*}
    tmp=${tmp%%"${tmp##*[!/]}"}
    printf '%s\n' "${tmp:-/}"
}

basename() {
    local tmp=${1%"${1##*[!/]}"}
    tmp=${tmp##*/}
    tmp=${tmp%"${2/"$tmp"}"}
    printf '%s\n' "${tmp:-/}"
}

    Parameter expansion

    ExpansionEffect
    ${!VAR}Access variable by name stored in VAR
    ${VAR#P}Remove shortest match from start
    ${VAR##P}Remove longest match from start
    ${VAR%P}Remove shortest match from end
    ${VAR%%P}Remove longest match from end
    ${VAR/P/R}Replace first match
    ${VAR//P/R}Replace all matches
    ${#VAR}Length in characters
    ${VAR:OFFSET:LEN}Substring
    ${VAR:-DEFAULT}Default if empty/unset
    ${VAR:=DEFAULT}Set default if empty/unset
    ${VAR:?ERROR}Error if empty

    Conditionals

    • File tests: -e exists, -d directory, -f regular file, -r readable, -w writable, -x executable, -s non-empty, -L symlink, -N modified since last read.
    • File comparison: file -nt file2 newer, file -ot file2 older, file -ef file2 same inode.
    • Variable tests: -z zero length, -n non-zero, -v has value, -R is nameref.

    uuid() {
    C="89ab"
    for ((N=0;N<16;++N)); do
        B="$((RANDOM%256))"
        case "$N" in
            6)  printf '4%x' "$((B%16))" ;;
            7)  printf '%c%x' "${C:$RANDOM%${#C}:1}" "$((B%16))" ;;
            3|5|7|9) printf '%02x-' "$B" ;;
            *) printf '%02x' "$B" ;;
        esac
    done
    printf '\n'
}

    VERSION=${IMAGE_TAG#v}       # v1.2.3 → 1.2.3     (shortest prefix)

    ${VAR##pattern}Remove prefix (longest)
    ${VAR%pattern}Remove suffix (shortest)${IMAGE_TAG%-beta*}

    Shebang choice

    ShebangUse When
    #!/bin/bashNeed bash features (arrays, [[ ]], brace expansion)
    #!/usr/bin/env shMaximum portability, POSIX compliance only

    #!/usr/bin/env sh finds sh via PATH and is portable across Unix-like systems; #!/bin/bash assumes bash at /bin/bash — predictable but less portable.

    Shell magic and easter eggs

    • Zsh Tetris. Zsh ships a native tetriscurses module: autoload -Uz tetriscurses, then tetriscurses. It needs the curses module; arrow keys move/rotate, Down drops, no Vim bindings. Zsh stays smaller than bash even with these modules.
    • The fork bomb. :(){ :|:& };: defines a function : that pipes itself into itself in the background and immediately calls it — :() defines it, :|: pipes it, & backgrounds it, ;: runs it. Process count grows exponentially until the OS cannot cope and even htop may fail to open.
    • Calendar oddity. cal 1752 shows September 1752 missing 11 days (Sept 3–13) — the British Empire’s switch to the Gregorian calendar is preserved in the utility.

    🚨 Never run the fork bomb on a production system or any machine you cannot reboot.

    PS1 logic and : > file.txt are the interactive tricks above; cal and the fork bomb are the historical colour — command-line utilities keep cultural shifts baked into their logic.
